# Интерактивное резюме — Кобылин Тимур Евгеньевич

Страница подготовлена для публикации через **GitHub Pages**.

## Публикация

1. Создайте на GitHub публичный репозиторий, например `timur-resume`.
2. Загрузите `index.md` в корень репозитория и папку `assets` с `avatar.png`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. Если GitHub Pages не обрабатывает `index.md` с выбранной темой автоматически, создайте файл `_config.yml` с содержимым:
   ```yml
   theme: minima
   ```
6. После публикации GitHub покажет публичный адрес вида `https://USERNAME.github.io/REPOSITORY/`. Это пример формата, не готовая ссылка.
7. Откройте опубликованный адрес в режиме инкогнито и проверьте кнопки email, телефона и Telegram, а также раскрывающиеся блоки проектов.

## Важно перед публикацией

- В исходном PDF не было публичных ссылок на проекты или репозитории. В карточках проектов оставлены пометки, куда добавить ссылки при наличии.
- Аватар извлечён из исходного PDF; это графический значок, а не фотография.
- Резюме содержит персональные контакты. Публикуйте их открыто только если владелец резюме согласен.
- Не добавляйте материалы работодателей, которые содержат конфиденциальные сведения.
